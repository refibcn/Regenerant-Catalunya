# Project Data Collection Template - Specification

**Purpose:** Single Google Doc (Word format) for collecting all project information needed for Phase 1 evaluation and Karma GAP submissions.

**Format:** Google Docs (Word document format, not spreadsheet)

---

## Document Structure

### Document Features

- **Hyperlinked Table of Contents** — Quick navigation to any project section
- **Clear section headers** — Consistent formatting (Heading 1 for projects, Heading 2 for subsections)
- **Bookmarks** — For quick jumping between sections
- **Comment threads** — For questions and feedback
- **Version history** — Enabled for tracking changes

## Access & Permissions

### Recommended Permissions

- **ReFi Barcelona team:** Full edit access
- **Project representatives:** Edit access (can edit their own section)
- **Network coordinators (Oriol, Mariló):** View access to their network's projects
- **Read-only link:** Optional, for public transparency

### Permission Management

- Use Google Docs sharing settings
- Consider using section-level comments for project-specific questions
- Enable version history for tracking changes

---

## Usage Instructions

### For Projects

1. Navigate to your project section using the Table of Contents
2. Fill in all sections (A through G)
3. Use comments to ask questions
4. Update status fields as you progress
5. Submit activities to Karma when ready

### For ReFi Barcelona Team

1. Monitor progress via Master Index
2. Review project sections regularly
3. Provide support via comments
4. Track completion status
5. Use for evaluation preparation

---

## Template Creation Steps

1. Create new Google Doc
2. Set up Table of Contents (Insert → Table of contents)
3. Create Master Index section
4. Create project sections (one per project)
5. Add bookmarks for navigation
6. Set up sharing permissions
7. Share with projects and coordinators
8. Provide usage instructions
