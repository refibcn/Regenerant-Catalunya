**Key Flows:**

1. **Projects → Data Collection Document**
   - Project information
   - Wallet details
   - Activity documentation
   - Self-assessments

2. **Data Collection Document → Karma GAP**
   - Organized information
   - Ready-to-submit activities
   - Supporting documents

3. **Karma GAP → Evaluation**
   - Public, on-chain documentation
   - Verifiable impact records
   - Evaluation scores

4. **Evaluation → Allocation**
   - Scores calculated
   - Allocations determined
   - Distribution prepared

5. **Allocation → Disbursement**
   - On-chain transactions
   - Public records
   - Project notifications
