# Activities Report – Google Doc Template Specification

**Purpose:** Define the structure of the per‑project **Activities Report** G oogle Doc that projects will use during the first documentation workshops. This template is based on the Notion [`Activities Report [Template]`](../Activities%20Report%20%5BTemplate%5D%202bc6ed0845cb81b887fde2a5451ccdc3.md), adapted to Google Docs conventions.

**Format:** One **Google Doc per project** (duplicated from a master template).

---

## 1. Document Layout & Features

Each Activities Report Google Doc should include:

- **Title:** `Informe de actividades – [Nombre del proyecto]`
- **Short intro box** at the top explaining how to use the document
- **Section for project info and Drive folder link**
- **Reusable activity block** (one per activity) with:
  - Activity name and description
  - Dates
  - Outputs – Deliverables (things)
  - Outputs – Metrics (numbers)
- **One fully filled example activity** to model the expected level of detail

### 1.1 Intro / “How to use this template” box

At the very top, add a shaded box (e.g. Google Docs “Table” with 1 column) with:

- **Heading:** “Cómo usar este documento”
- Bullet points (short, simple Spanish) covering:
  - “Este documento es tu **informe de actividades** para Regenerant Catalunya.”
  - “Rellena **un bloque por actividad importante** de tu proyecto.”
  - “Cada actividad incluye: descripción, fechas, entregables (cosas) y métricas (números).”
  - “No hace falta escribir perfecto; lo importante es que quede claro qué habéis hecho.”
  - “Más adelante utilizaremos este informe para subir las actividades a **Karma GAP**.”

## 3. Activity Block Structure

The core of the template is a **block that can be duplicated** for cada actividad. We replace the Notion “New” button with clear formatting + instructions: “Copia y pega este bloque para añadir nuevas actividades”.

### 3.1 Activity heading

**Heading style:** `2. Actividades` (once), then subheadings for each activity, e.g.:

- `Actividad 1 – [Nombre de la actividad]`
- `Actividad 2 – [Nombre de la actividad]`

Under each activity subheading, add a short italic prompt:

> _Describe aquí una actividad importante de tu proyecto. Usa un bloque por actividad._

### 3.2 Fields in each activity block

Represent the fields from the Notion template using **bold labels + normal text** (no tables required for minimum version), in this order:

- **Descripción:**  
  _¿Qué habéis hecho? Explica brevemente la actividad, las personas implicadas y el contexto._

- **Fechas (inicio – fin):**  
  _Ej.: marzo–abril 2025, o una fecha concreta si fue un solo día._

- **Lugar:**  
  _Barrio / pueblo / territorio donde tuvo lugar la actividad._

- **Outputs – Entregables (cosas producidas):**

  Use a simple bullet list with the following sub‑fields inside each bullet:

  - **Nombre del entregable:**  
  - **Enlace / prueba:** (link a carpeta, archivo, post, etc.)  
  - **Descripción breve:** _¿Qué es y para qué sirve?_

- **Outputs – Métricas (números):**

  Another bullet list, with sub‑fields:

  - **Métrica:** _¿Qué estáis contando? (personas, sesiones, hectáreas, comidas, etc.)_  
  - **Descripción:** _Cómo se contó / qué representa ese número._  
  - **Valor:** _Número (puede ser estimado si no hay dato exacto)._  
  - **Enlace / prueba (si existe):_ asistencia, hoja de cálculo, informe, etc._

Optional final field per activity (plain text):

- **Comentarios / contexto adicional (opcional):**  
  _Cualquier matiz importante sobre la actividad, acuerdos, conflictos, aprendizajes, etc._

## 4. Example Activity Block (to include in template)

At the end of the document (or right after the first empty block), include **one fully filled example**. This should be clearly marked as an example and not part of the project’s own work.

Suggested example (adapt it into natural Spanish in the actual Google Doc):

- **Actividad:** “Taller comunitario sobre agroecología en Pomezia”
- **Descripción:** “Organizamos un taller de 3 horas en el espacio de Pomezia para compartir prácticas agroecológicas con vecinas y proyectos de la red. Preparación conjunta con el equipo de Keras Buti y dinamización participativa.”
- **Fechas:** “3 de octubre de 2025 (1 sesión)”
- **Lugar:** “Pomezia, L’Hospitalet de Llobregat”

**Outputs – Entregables (ejemplo):**

- **Nombre del entregable:** Presentación y materiales del taller  
  **Enlace / prueba:** link a carpeta de Drive con diapositivas y fichas impresas  
  **Descripción breve:** Materiales utilizados durante el taller y que se pueden reutilizar en futuras sesiones.

- **Nombre del entregable:** Carpeta de fotos del taller  
  **Enlace / prueba:** link a carpeta de fotos  
  **Descripción breve:** Documentación visual para memoria del proyecto y comunicación.

**Outputs – Métricas (ejemplo):**

- **Métrica:** Personas participantes  
  **Descripción:** Número de personas que asistieron al menos a la mitad del taller.  
  **Valor:** 26  
  **Enlace / prueba:** hoja de asistencia escaneada en la carpeta de Drive.

- **Métrica:** Proyectos representados  
  **Descripción:** Número de proyectos diferentes presentes en el taller.  
  **Valor:** 9  
  **Enlace / prueba:** lista de proyectos en la misma hoja de asistencia.

## 5. Google Docs “Functionality” Notes (Notion → Docs)

To translate Notion functionality into Google Docs:

- **Notion “New” button for activities →** Instruction text:  
  - “Para añadir una nueva actividad, copia y pega todo el bloque de campos de una actividad anterior y cambia la información.”
- **Notion database properties →** Simple **bold labels** + normal text (no need for rich schema).
- **Links to proofs / evidence →** Plain URLs or linked text pointing to:
  - Google Drive carpetas o archivos
  - Public URLs (webs, redes sociales, etc.)
- **Consistency:** Use **Heading 1** for the document title (only once), **Heading 2** for `1. Información básica del proyecto` and `2. Actividades`, and **Heading 3** for each activity heading.

---

## 6. Creation & Duplication Process

1. Create a **master template** Google Doc following this specification (with one empty activity block + one example block).  
2. Store it in a central folder for the program (e.g. “Regenerant Catalunya – Plantillas”).  
3. For each project:
   - Make a copy of the template  
   - Rename it to `Informe de actividades – [Nombre del proyecto]`  
   - Fill the project header section (name, network, etc.)  
   - Share edit access with the project team and relevant coordinators.
4. During the first documentation workshops (Keras Buti / Miceli), facilitators:
   - Open each project’s Doc  
   - Help complete at least one activity block together  
   - Leave clear homework on how many additional activities to document.
