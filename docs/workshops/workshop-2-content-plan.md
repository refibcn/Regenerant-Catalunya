## Module 2: Understanding Evaluation Criteria (20 min)

### Key Points

**Overview of 4 Criteria:**

1. **Local Impact (35%)** — Ecological, social, economic impact in Catalonia
   - Examples: Ecosystem restoration, community health, cooperatives
   - What evaluators look for: Measurable outcomes, documentation, network integration

2. **Web3 Adoption (25%)** — Wallet setup, Karma usage, tool adoption
   - Examples: Regular Karma updates, wallet usage, tool integration
   - What evaluators look for: Consistent reporting, engagement

3. **Resource Efficiency (25%)** — Impact relative to resources
   - Examples: Efficient operations, transparency, results for project size
   - What evaluators look for: Efficiency, accountability

4. **Clear Plans (15%)** — Specific goals, milestones, alignment
   - Examples: Realistic timelines, defined milestones, regenerative alignment
   - What evaluators look for: Clear planning, trackable progress

### Interactive Exercise

**Self-Assessment Activity (5 min):**
- Participants assess their project against each criterion
- Identify strengths and gaps
- Note questions for Q&A

## Module 3: Introduction to Karma GAP (20 min)

### Key Points

**What is Karma GAP?**
- On-chain platform for transparent impact reporting
- Creates a living, public "project resume"
- Makes impact visible and verifiable

**Why Use Karma?**
- Builds on-chain reputation
- Makes impact visible to future funders
- Improves discoverability
- Aligned with Common Approach guidelines

**How It Works:**
- Activities logged on-chain (public, verifiable)
- Follows Common Approach framework (Activities → Outputs → Outcomes → Impact)
- Can be updated over time
- Links to supporting documents

**Common Approach Framework:**
- **Activities:** What you do
- **Outputs:** What you produce
- **Outcomes:** Short-term changes
- **Impact:** Long-term changes

## Module 5: Documenting Activities (30 min)

### Key Points

**What to Document:**

**Past Activities (Minimum 3):**
- Completed projects or initiatives
- Events, workshops, activities
- Impact achieved (ecological, social, economic, cultural)
- Partnerships or collaborations
- Community engagement

**Future Plans (Minimum 3):**
- Planned activities for 2026
- How funding will be used
- Expected outcomes
- Timeline and milestones
- Resources needed

**How to Document Effectively:**

1. **Be Specific**
   - Use numbers, dates, locations
   - Quantify where possible (participants, hectares, etc.)

2. **Show Evidence**
   - Include photos, reports, data
   - Link to supporting documents

3. **Connect to Values**
   - Link to regenerative, cooperative values
   - Show alignment with Catalan priorities

4. **Think Long-term**
   - Show how work contributes to bioregional regeneration
   - Demonstrate systemic thinking

**Activity Form Structure:**
- Title/Name
- Description
- Date(s)
- Location
- Participants/Beneficiaries
- Impact metrics
- Supporting documents
- Alignment with criteria

### Examples

**Good Example:**
- "Ecosystem Restoration Workshop - La Garrotxa"
- Date: October 15, 2025
- Location: La Garrotxa, Girona
- Participants: 25 local farmers and community members
- Impact: 3 hectares of degraded land identified for restoration, 15 farmers committed to regenerative practices
- Supporting: Photos, workshop report, participant list

**Weak Example:**
- "We did a workshop"
- No dates, no numbers, no documentation

### Interactive Exercise

**Practice Activity (10 min):**
- Participants draft one activity description
- Share in breakout rooms for feedback
- Refine based on feedback

## Module 6: Using the Data Collection Document (15 min)

### Key Points

**Purpose:**
- Organize information before submitting to Karma
- Self-assess against evaluation criteria
- Track progress and status
- Centralized location for all project documentation

**How to Use It:**

1. **Navigate to Your Section**
   - Use Table of Contents
   - Find your project section

2. **Fill in All Sections**
   - Project Information (A)
   - Wallet Setup (B)
   - Past Activities (C) — Minimum 3
   - Future Plans (D) — Minimum 3
   - Supporting Documents (E)
   - Evaluation Alignment (F)
   - Notes & Support (G)

3. **Update Status**
   - Mark activities as Draft / Ready for Karma / Submitted
   - Track progress

4. **Use Comments**
   - Ask questions
   - Request feedback
   - Get support

**Benefits:**
- Ensures you have all information ready
- Helps organize thoughts before Karma submission
- Self-assessment identifies strengths and gaps
- Tracks progress toward deadlines
