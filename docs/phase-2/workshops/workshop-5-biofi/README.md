## Key Concepts Introduced

### BioFi (Bioregional Finance Infrastructure)

**Definition:**
Financial systems and infrastructure that serve bioregional regeneration instead of extraction

**Core Principles:**
1. Place-based (organized around bioregions)
2. Transparent (on-chain reporting)
3. Participatory (community governance)
4. Replicable (open-source templates)
5. Regenerative (serving ecosystem health)
6. Cosmo-local (global resources + local knowledge)

**Why It Matters:**
Traditional finance is extractive and disconnected from place. BioFi creates infrastructure for capital to flow to bioregional regeneration.

### Regenerant Catalunya as Pilot

**Testing:**
- Can cooperative networks govern Web3 tools effectively?
- Does on-chain reporting add value for regenerative projects?
- What support do communities need?
- How to balance local autonomy with global connection?

**Documenting:**
- Everything learned → open-source knowledge products
- Successes and challenges → honest reporting
- Templates and frameworks → replicable

**Sharing:**
- Final report (public, multi-language)
- Replication toolkit
- With global ReFi ecosystem

### Global Ecosystem Connections

**Regenerant Catalunya connects participants to:**
- ReFi DAO & local nodes (Barcelona, Mediterranean, global)
- Gitcoin & public goods funding mechanisms
- Celo ecosystem & mobile-first blockchain
- Regen Network & ecological data protocols
- Cooperative & solidarity economy movements

**Opportunities from connection:**
- Future funding possibilities
- Collaboration with other bioregions
- Visibility and recognition
- Influence on tool development
- Knowledge sharing and movement building

## Feedback Collection Strategy

### Three-Tiered Approach

**1. Live Polls (During Workshop):**
- Quick quantitative data
- Immediate results visible
- Creates engagement
- 4-5 questions maximum

**2. Open Discussion (During Workshop):**
- Qualitative insights
- Deeper understanding
- Authentic voices
- 3-4 volunteers share

**3. Written Form (Asynchronous):**
- Comprehensive feedback (26 questions)
- Thoughtful, detailed responses
- Submitted by Feb 28
- Allows reflection time

### Data Use

**For Final Report:**
- Participant experience section
- Recommendations for future rounds
- Authentic quotes and stories
- Program improvement insights

**For Ecosystem:**
- BioFi methodology learnings
- Community tool adoption patterns
- Support needs for Web3 governance
- Cooperative-Web3 integration insights

**For Future Rounds:**
- What to keep, change, add, stop
- Workshop design improvements
- Tool selection guidance
- Support structure optimization
