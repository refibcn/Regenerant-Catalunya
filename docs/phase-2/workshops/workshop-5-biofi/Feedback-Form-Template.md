## Implementation Notes (For Form Creator)

### Platform Recommendation

**Google Forms:**
- ✅ Free, accessible
- ✅ Automatic data collection
- ✅ Can export to spreadsheet
- ✅ Multi-language support
- ✅ Anonymous response option

**Typeform:**
- ✅ More beautiful interface
- ✅ Better user experience
- ✅ Logic jumps (skip irrelevant questions)
- ❌ Requires paid plan for full features

**Alternative:**
- Notion forms
- Airtable forms
- Microsoft Forms

### Form Settings

**Privacy:**
- Don't require Google sign-in (allow anonymous)
- Don't collect email automatically (ask for it)
- Clear privacy statement
- GDPR compliant

**Accessibility:**
- Mobile-friendly
- Screen reader compatible
- Simple, clear language
- Progress indicator
- Save and continue option

**Distribution:**
- Short URL: bit.ly/regenerant-feedback or similar
- QR code for easy mobile access
- Share in workshop, email, WhatsApp group
- Reminder 1 week before deadline

### Data Management

**Collection:**
- Real-time response tracking
- Export to spreadsheet weekly
- Backup responses regularly

**Analysis:**
- Quantitative: Calculate averages, distributions
- Qualitative: Code open responses, identify themes
- Comparative: Miceli vs La Fundición, Phase 1 vs Phase 2
- Longitudinal: Track over time if repeated

**Reporting:**
- Aggregated data in final report
- Anonymized quotes (with permission)
- Visual charts for key metrics
- Narrative synthesis of themes
