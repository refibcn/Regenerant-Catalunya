## Visual Design Guidelines

### Color Palette

**Primary Colors:**
- **Regenerant Green:** #2E7D32 (nature, growth)
- **ReFi Blue:** #1976D2 (trust, technology)
- **Catalunya Gold:** #F9A825 (warmth, local)

**Secondary Colors:**
- **Earth Brown:** #5D4037 (grounding)
- **Cooperative Red:** #C62828 (action, community)
- **Light Green:** #81C784 (accent)

**Neutrals:**
- White: #FFFFFF
- Light Gray: #F5F5F5
- Dark Gray: #424242

### Typography

**Headings:**
- Font: Montserrat or similar (bold, modern, sans-serif)
- Size: 44-54pt for titles, 32-36pt for subtitles
- Color: Dark gray or primary colors

**Body Text:**
- Font: Open Sans or similar (clean, readable, sans-serif)
- Size: 20-24pt for body, 16-18pt for captions
- Color: Dark gray (#424242)
- Line spacing: 1.5

**Emphasis:**
- Bold for key terms
- Color highlights for critical info
- Italics sparingly

### Imagery Guidelines

**Photo Style:**
- Natural, authentic (not stock)
- Catalunya landscapes and projects
- People in collaborative settings
- Cooperative/community activities
- High quality but approachable

**Icons:**
- Flat, modern style
- Consistent set (all same style)
- Color or monochrome
- Size: Visible from distance

**Diagrams:**
- Simple, clean lines
- Limited colors (2-3 max)
- Clear labels
- Arrows show flow/direction

### Layout Principles

**Consistency:**
- Same slide template throughout
- Consistent placement of logos
- Standard margins and spacing
- Predictable structure

**Hierarchy:**
- Clear visual hierarchy (title → subtitle → body)
- Use size, color, position to guide eye
- Most important info largest/boldest
- White space for breathing room

**Accessibility:**
- High contrast (text vs background)
- Large, readable fonts
- Avoid red-green combinations
- Test legibility from distance

## Presentation Tips

### Setup

**Before Workshop:**
- Load slide deck 15 minutes early
- Test all animations/transitions
- Have backup version ready (PDF)
- Test hybrid screen visibility
- Bookmark key slides for quick navigation

**During Workshop:**
- Use presenter view (notes visible to you)
- Have timer/clock visible
- Keep backup slides ready
- Use slide numbers to navigate

### Facilitation Integration

**Don't just read slides:**
- Slides support your facilitation, not replace it
- Elaborate on points with stories/examples
- Connect to participants' context
- Use slides as reference, not script

**Manage pacing:**
- Don't rush through slide content
- Pause for questions
- Skip slides if running behind (have backup)
- Extend time if rich discussion emerges

**Interactive elements:**
- Invite participants to read aloud
- Ask questions before revealing answers
- Use slides to structure activities
- Return to key slides for reference
