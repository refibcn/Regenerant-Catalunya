# NotebookLM Video Style Guide
## Safe Multisig for Democratic Organizations

**Purpose:** Visual + tonal direction for AI-generated video narration  
**Output:** 2 videos (ES-ES + CAT, ~20 min each)  
**Audience:** Democratic organizations, cooperatives, DAOs

---

## VISUAL STYLE

### Color Palette

**Inspiration:** Regenerant Catalunya brand + cooperative/ESS (social and solidarity economy) aesthetics - warm, organic, earthy

| Element | Color | Use |
|---------|-------|-----|
| **Primary** | Deep Forest Green (#1B4332) | Main backgrounds, authority |
| **Secondary** | Coral/Orange (#E63946) | Highlights, actions, emphasis |
| **Tertiary** | Soft Purple (#A8DADC) | Secondary highlights, transitions |
| **Neutral Light** | Off-white (#F1FAEE) | Text backgrounds, clarity |
| **Neutral Dark** | Charcoal (#2A2A2A) | Text, contrast |

### Visual Elements

**Preferred:**
- ✅ Geometric shapes (hexagons, circles, networks) — represent decentralization
- ✅ Connected nodes/dots — symbolize multisig structure
- ✅ Clean lines and diagrams — simplify complex concepts
- ✅ Warm, hand-drawn illustrations — feel human, not corporate
- ✅ Icons for key concepts (lock, keys, approval, transparency)
- ✅ Flowing transitions — organic, not jarring

**Avoid:**
- ❌ Harsh corporate aesthetics (blue/gray tech sterility)
- ❌ Cryptocurrency "moon lambo" imagery
- ❌ Overly complex 3D renderings
- ❌ Rapid cuts/flashing (accessibility + overwhelm)
- ❌ Generic stock photos

### Specific Visual Metaphors

**The "Safe Box with 5 Keys"**
- Open with 1 key shown, then 2, then 3, then 5
- Show threshold: "3 of 5 needed"
- Animate keys combining to unlock
- Use throughout as recurring visual

**Trust Network**
- Show 5 people (simple silhouettes)
- Draw connecting lines between them
- Highlight that no single person controls everything
- Animate approval flow through the network

**Transparency Concept**
- Start with closed/opaque Safe
- Gradually become transparent
- Show transactions flowing through as visible
- End with completely transparent (but secure)

### Slide/Frame Pacing

- **Complex concepts:** 8-12 seconds per visual
- **Simple concepts:** 3-5 seconds per visual
- **Key metaphors:** 15-20 seconds (enough to absorb)
- **Transitions:** Smooth fades or organic wipes (1-2 sec)
- **Text on screen:** 5+ seconds minimum (accessibility)

## AI HOST DIRECTION

### Tone & Voice

**Primary:** Warm, confident, educational  
**Secondary:** Practical, grounded, non-condescending  
**Avoid:** Corporate, hyper-technical, salesy

**Key phrase:** "This is how real organizations do this. We're showing you what works."

### Pacing & Delivery

**Speed:** Moderate pace, **not rushed**
- Give concepts time to land
- Pause after key points (1-2 sec)
- Let visuals breathe

**Emphasis:**
- Emphasize **democratic governance**, not just tech
- Emphasize **security as practice**, not just rules
- Emphasize **real organizations**, not hypotheticals

**Emotional Arc:**
1. **Opening:** Problem + hope (0-2 min)
2. **Middle:** Education + empowerment (2-16 min)
3. **Closing:** Call to action + support available (16-20 min)

### Language Choices

**Use:**
- "Your organization"
- "Democratic decision"
- "Transparent"
- "Collectively"
- "Trust"
- "Resilience"

**Avoid:**
- "Crypto" (use "digital" or "blockchain")
- "Decentralized finance" (too jargony)
- "Smart contracts" (unless specifically needed)
- "Trustless" (paradoxical — multisig is about trust)
- "HODL" / crypto slang

### Section-by-Section Direction

#### Opening (0:00–1:00)

**Tone:** Welcoming, validating

**Direction:**
- Acknowledge the problem directly ("traditional finance has failed organizations like yours")
- Show empathy for pain points
- End with hope ("there's a better way")
- Visual: Start with problem imagery (locked doors, barriers), transition to open/light imagery

**Host focus:** Sound like you understand their struggle, not lecturing them

---

#### Part 1: Why Traditional Finance Fails (1:00–3:00)

**Tone:** Serious, but problem-focused (not doom)

**Direction:**
- Present each barrier clearly (deplatforming, opacity, cost, access, hierarchy)
- Use real-world examples without naming specific organizations
- Show visual representation of each barrier
- Conclude: "This is why alternatives exist"

**Host focus:** "Here's the real problem. It's not theoretical."

---

#### Part 2: Why Web3 Solves This (3:00–5:30)

**Tone:** Optimistic, but grounded

**Direction:**
- Directly address each pain point from Part 1
- Explain **what** Web3 offers, not just **how** it works technically
- Use parallels to familiar concepts (security like math, not like banks)
- Address common objections briefly (energy, cost, legality)

**Host focus:** "This is how other organizations are solving this. You can too."

---

#### Part 3: How Multisig Works (5:30–8:00)

**Tone:** Patient, teaching

**Direction:**
- Use the "5 keys in a safe" metaphor heavily
- Animate it multiple times from different angles
- Explain threshold concept clearly
- Show why no single person is a liability
- Visual: Heavy use of the Safe Box + Keys animation

**Host focus:** Speak slowly, use analogies, make it visual more than verbal

---

#### Part 4: Safe as Tool (8:00–10:30)

**Tone:** Practical, demystifying

**Direction:**
- Show each step simply (create, add signers, set threshold, propose, approve, execute)
- Don't go into technical details; focus on workflow
- Show it works across multiple networks (Ethereum, Gnosis, Celo, etc.)
- Emphasize: "Safe is just the tool. You decide the rules."

**Host focus:** "This is how it actually works, step by step. It's not magic."

---

#### Part 5: Democratic Governance Principles (10:30–15:00)

**Tone:** Empowering, foundational

**Direction:**
- These are THE most important 5 minutes
- Use different visual style for each principle (icons, animations, real-world scenarios)
- Give each principle 1 minute
- Show consequences of ignoring each principle

**Host focus:** Slow down. These are foundational. Make each one memorable.

**Principles visual breakdown:**
1. **Distributed Trust** — Network diagram, no central node
2. **Transparency** — Layers becoming visible/clear
3. **Process Matters** — People meeting + technology together
4. **Security as Practice** — Continuous vigilance, not one-time rules
5. **Start Simple** — Growth curve from basic to advanced

---

#### Part 6: Real Workflow Example (15:00–17:00)

**Tone:** Concrete, practical

**Direction:**
- Use the agriculture co-op example
- Show timeline: Mon (propose) → Tue (review) → Wed (execute)
- Animate each approval
- Show final transparency/recording
- Use character names, make it feel real

**Host focus:** Tell it like a story. "Here's what happens in real time."

---

#### Part 7: Common Mistakes (17:00–18:30)

**Tone:** Honest, preventative

**Direction:**
- 6 common mistakes, 15 seconds each
- Show the mistake + the fix
- Use red/warning color for the mistake, then green for the fix
- Don't make it scary; make it "here's how to avoid this"

**Host focus:** "Organizations have learned these lessons. Here's what they figured out."

---

#### Closing (18:30–20:00)

**Tone:** Empowering, forward-looking

**Direction:**
- Recap: Safe is just the tool; YOU decide the rules
- Emphasize: This is how real organizations work
- Call to action: "Next steps are simple"
- End with: Help is available, you're not alone

**Host focus:** Sound confident but humble. "You can do this. We've seen it work."

## SPECIFIC VISUAL SEQUENCES

### "5 Keys in a Safe" Animation (Recurring)

**First intro (Part 3):**
- Safe appears closed
- Show 5 people around it
- Each gets a key (1, 2, 3, 4, 5)
- Show "3 of 5 needed"
- 3 keys combine and unlock

**Each time thereafter:**
- Simpler, faster version (3-4 sec)
- Reinforces the concept

### Network Diagram (Part 5, Principle 1)

- 5 nodes representing people
- Draw connections between all
- Highlight that no node is central
- If one fails, others still work
- Use pulse animation to show active network

### Transparency Progression (Part 5, Principle 2)

- Start with opaque/closed box
- Gradually become transparent
- Show transactions flowing through
- End with completely see-through (but secure)
- Use color progression: dark → light → crystal clear

### Democratic Decision Flow (Part 6)

- Monday: Proposal appears (becomes sticky note or card)
- Tuesday: Reviews appear (checkmarks accumulate)
- Wednesday: Execute (payment arrow flows)
- End state: Transaction recorded permanently

## ACCESSIBILITY NOTES

- **Text on screen:** Minimum 5 seconds
- **Contrast:** Ensure all text has 4.5:1 contrast ratio
- **Color:** Don't rely on color alone (use icons + text)
- **Pacing:** Not too fast; allow processing time
- **Audio:** Clear narration, no background music drowning it out
- **Captions:** Spanish/Catalan subtitles auto-generated by NotebookLM
