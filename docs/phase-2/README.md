## Executive Summary

Phase 2 of Regenerant Catalunya shifts from individual project engagement to **network-level governance tool pilots**. The focus is on supporting Miceli Social and La Fundició/Keras Buti networks in implementing Web3 governance tools that fit their specific cultures and needs.

**What Phase 2 Entails:**

Phase 2 is a simplified, flexible program centered around key interaction points (calls and workshops) with network leaders Oriol (Miceli) and Mariló (La Fundició). The approach prioritizes **quality over quantity**—aiming for one solid, documented case study rather than multiple incomplete attempts. The structure adapts to each network's capacity: La Fundició receives a single comprehensive afternoon session focused on hands-on Hum Community implementation, while Miceli engages in two focused sessions covering Web3 tools and IDK case implementation.

The program emphasizes **simplification** ("How can we make this as simple as possible?") and validates network interest before committing resources. Tool selection is network-driven, with Safe multisig recommended for Miceli's tech-forward culture and Hum Community for La Fundició's cooperative-traditional approach. The timeline is flexible—March serves as a progress checkpoint, not a hard deadline.

## Strategic Approach

### Core Principles (From Jan 28 Work Session)

**1. Simplify as Much as Possible**
- "I just think this is way too much stuff" - reduce complexity
- Single comprehensive session for La Fundició instead of multiple workshops
- Focused, efficient sessions for Miceli
- Avoid overwhelming networks with too many activities

**2. Network-Level Focus**
- Shift from individual projects to network pilots
- Primary engagement: Network leaders (Oriol, Mariló)
- Additional participants welcome but not required
- Less intensive project-level engagement

**3. Quality Over Quantity**
- One solid, documented case study > multiple incomplete attempts
- Avoid scenario where neither implementation is completed satisfactorily
- Document everything for future funding opportunities
- Focus on deliverables that can be packaged as concrete outputs

**4. Validation Before Commitment**
- Kickoff call validates interest BEFORE major preparation
- Present options, don't impose
- Emphasize choice and flexibility
- Pivot if validation shows poor fit

**5. Timeline Flexibility**
- March deadline not absolute - program can extend beyond
- March report: progress update, not final comprehensive report
- Final report when work is complete
- Quality results > arbitrary deadlines

**6. Case Study Positioning**
- Every activity positioned as future funding evidence
- Document methodology for ecosystem sharing
- Create replicable model for other bioregions
- Photo documentation throughout

**Framing:** Cooperative, solidarity economy, mutual aid

**Workshop Style:** Patient, deliberative, consensus-building

**Tool Recommendation:** Hum Community (fits cooperative culture)

**Workshop Structure:** Single afternoon comprehensive session

**Success:** Tool integrated into cooperative practices

**Communication:** In-person preferred, patient pace, intensive support

**Key Principle:** "With hospital, we should try and just like, Make it simplify as much as possible"

## Tool Implementation Strategy

### Tool Assignment

| Tool | Best Fit Network | Implementation Effort | Support Needs | Success Indicators |
|------|------------------|----------------------|---------------|-------------------|
| **Safe Multisig** | Miceli (tech-forward) | Medium | Light (self-manage) | Active multisig with real transactions |
| **Hum Community** | La Fundició (cooperative) | High | Intensive (hands-on) | Community setup + member onboarding |
| **IDK Mini-Program** | Both networks | Medium | Moderate (facilitated) | Governance maps + protocol designs |

### Decision Framework

**Validation Process:**
1. Kickoff call validates network interest
2. Workshops confirm specific tool selection
3. Implementation plans ready for immediate execution
4. Pivot options if validation shows poor fit

**If Networks Not Interested:**
- Focus on IDK mini-program (valuable standalone)
- Governance documentation and mapping
- Reduce scope to what's achievable
- Document learnings for future

## Success Metrics

### Phase 2 is Successful When:

- ✅ At least one network has active governance tool deployment
- ✅ Documented case study showing actual tool usage
- ✅ Comprehensive final report (methodology + learnings)
- ✅ Replicable materials for other bioregions
- ✅ Strong positioning for future funding opportunities
- ✅ Networks feel empowered and supported (not overwhelmed)

### Quality Indicators:

- Networks choose tools (not imposed on them)
- Implementation fits network culture and capacity
- Real usage with actual decisions/transactions
- Positive participant feedback
- Clear documentation of methodology
- Ecosystem contribution through open-source materials
