# Institutional Development Kit (IDK) Mini-Program

**Approach:** Mini-program within Regenerant Catalunya Phase 2  
**Networks:** Both Miceli Social and La Fundición/Keras Buti  
**Status:** Placeholder/Direction - To be developed with network input

---

## Overview

The Institutional Development Kit is a facilitation framework and methodology developed by Regen Foundation's Ecological Institutions program. Unlike Safe or Hum Community (which are software tools), IDK is a process for mapping existing governance structures, identifying decision-making patterns, and assessing where Web3 tools might add value.

**Core Purpose:**
Understand and document existing institutional knowledge before (or alongside) adopting new tools

**Why IDK as Mini-Program:**
- Honors existing governance wisdom in cooperative networks
- Creates foundation for informed tool adoption
- Produces valuable documentation for networks
- Connects to Regen Foundation's broader work
- Becomes standalone value beyond just tool selection
