# Hero Section Variations - Design Specification

## Base Design Elements

### Background

- **Image**: `/static/hero-background.png`
- **Size**: Full width (100vw)
- **Position**: Cover, centered
- **Min Height**: 75vh (mobile), 85vh (desktop)

### Card Styling

- **Background**: `rgba(33, 64, 51, 0.15)` (green highlight - transparent overlay)
- **Border**: `2px solid #214033` (green dark)
- **Padding**:
  - Mobile: `2rem 1.5rem`
  - Tablet: `2.5rem 2rem`
  - Desktop: `3rem 2.5rem`
- **Max Width**:
  - Mobile: `42rem`
  - Desktop: `45rem`
- **Margin**:
  - Mobile: `1.5rem 1.5rem 0`
  - Desktop: `3rem 3rem 0`
- **Position**: Top-left aligned

### Typography

- **Title (h1)**:
  - Font Size: `2.75rem`
  - Color: `#214033` (green dark)
  - Font Weight: Bold
- **Subtitle (p)**:
  - Font Size: `1rem` (base)
  - Color: `#214033` (green dark)
  - Line Height: `1.6`

### Colors Reference

- **Green Dark**: `#214033`
- **Green Highlight**: `rgba(33, 64, 51, 0.15)`
