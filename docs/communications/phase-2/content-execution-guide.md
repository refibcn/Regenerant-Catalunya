## PART 1: Weekly Planning Workflow

### Every Monday (During Weekly Ops Sync)

**1. Review Week Ahead Content**
- Check content calendar for this week's planned posts
- Identify which posts are scheduled
- Note any dependencies (workshops must happen first, photos needed, etc.)

**2. Assign Ownership**
- **Andrea:** Primary content creator, facilitator
- **Giulio:** Content calendar planning, coordination
- **Luiz Fernando:** Technical content, tool explanations, strategic posts
- Assign based on content type and team capacity

**3. Identify Visual Needs**
- What photos are needed? (from workshops, events)
- What graphics need creation? (infographics, diagrams)
- Who creates visuals? (Domenico for newsletter, team for social posts)
- Timeline for visual delivery

**4. Confirm Dependencies**
- Workshop dates confirmed?
- Article ready for publication?
- Visuals ready?
- Any blockers?

**5. Update Notion Tracking**
- Mark planned content as "In Progress"
- Assign owners
- Set due dates
- Flag visual needs

## PART 2: Content Production Process

### Step-by-Step Workflow

**1. Draft Content (Assigned Owner)**
- Use content calendar as starting point
- Adapt messaging based on actual events/outcomes
- Keep tone: Honest, accessible, ecosystem-focused
- Include specific details (not generic)

**2. Gather Visuals**
- Photos from events/workshops (with consent)
- Graphics from Domenico or create simple visuals
- Screenshots (anonymized if needed)
- Ensure visuals are high-quality and on-brand

**3. Internal Review (Team)**
- Share draft in team channel
- Review for accuracy, tone, clarity
- Check links and tags
- Get approval before publishing

**4. Scheduling/Publishing**
- LinkedIn: Schedule via LinkedIn or post directly
- Twitter: Post directly or use scheduling tool
- Blue Sky: Cross-post same content as Twitter
- Newsletter: Send via email platform (Mailchimp/Substack)

**5. Engagement Monitoring**
- Respond to comments within 24 hours
- Engage with shares and mentions
- Track key conversations
- Adjust future content based on engagement patterns

**6. Metrics Tracking in Notion**
- Update Notion database with:
  - Actual publish date
  - Views/impressions
  - Engagement (likes, comments, shares)
  - Notes/learnings

## PART 3: Notion Tracking Setup

### Database Properties

Create a Notion database with the following properties:

| Property | Type | Description |
|----------|------|-------------|
| **Date Scheduled** | Date | Planned publication date |
| **Platform** | Select | LinkedIn / Twitter / Blue Sky / Newsletter |
| **Content Type** | Select | Post / Thread / Article Link / Newsletter |
| **Title/Topic** | Text | Brief description of content |
| **Owner** | Person | Andrea / Giulio / Luiz Fernando |
| **Status** | Select | Planned / Draft / Review / Scheduled / Published |
| **Visuals Needed** | Checkbox | Yes/No |
| **Visual Notes** | Text | What visuals are needed, who creates them |
| **Links to Include** | Text | URLs to include in post |
| **Actual Publish Date** | Date | When actually published |
| **Views/Impressions** | Number | Platform metrics |
| **Engagement** | Number | Likes + comments + shares |
| **Notes/Learnings** | Text | What worked, what didn't, adjustments |

### Initial Setup Steps

**1. Create Database**
- Create new database in ReFi Barcelona Notion workspace
- Name: "Regenerant Catalunya Content Calendar"
- Use table view for easy scanning

**2. Import Planned Content**
- Add all content from updated calendar
- Mark all as "Planned" status initially
- Assign initial owners based on content type
- Set scheduled dates

**3. Set Up Views**
- **By Week:** Filter by date range (weekly view)
- **By Platform:** Filter by platform (LinkedIn, Twitter, etc.)
- **By Owner:** Filter by assigned person
- **By Status:** Filter by status (see what's pending)

**4. Weekly Workflow Integration**
- Every Monday: Review "Planned" items for the week
- Update status to "In Progress" when work begins
- Move to "Review" when draft ready
- Mark "Published" when live, add metrics
