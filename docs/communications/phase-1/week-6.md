## Newsletter Article

# 2025 Reflection: Building Infrastructure for Bioregional Regeneration in Catalonia

_As we close out 2025, we're reflecting on what we've built together and what's possible for bioregional regeneration._

## What We've Built Together

### Eleven Regenerative Projects Supported

From ecosystem restoration to urban community infrastructure, food sovereignty to housing cooperatives—we've supported diverse regenerative work across Catalonia:

**Rural Regenerative Work:**

- Fluvià River Basin Restoration
- Ecosystem restoration initiatives
- Sustainable agriculture projects
- Community-led conservation efforts

**Urban Regenerative Work:**

- La Olla Community Kitchen
- Housing cooperatives (Las Yuntas)
- Textile sovereignty (Laurel 31)
- Community infrastructure projects

Each project represents essential regenerative work that builds community resilience and addresses systemic challenges.

### €29,200 Funding Pool

Through collaboration between local partners and global Web3 funders, we created a replicable funding model:

- **€11,000** from local partners (Miceli Social, La Fundició/Keras Buti)
- **€18,200** matched by global Web3 funders via Localism Fund
- **Total:** €29,200 supporting 11 projects

This model demonstrates that local commitment can be amplified by global support, creating sustainable funding infrastructure for bioregional regeneration.

### Three Capacity-Building Workshops

Projects learned essential skills for ongoing regenerative finance:

**Workshop 1: Web3 Wallet Setup**

- Setting up wallets with social recovery
- Understanding transparent fund management
- Connecting to impact reporting tools

**Workshop 2: KarmaGap Impact Documentation**

- Creating verifiable, on-chain impact records
- Setting metrics and tracking progress
- Building credibility with funders

**Workshop 3: Regenerative Measurement**

- Refining impact metrics
- Connecting activities to outcomes
- Building capacity for ongoing documentation

### Network Infrastructure

Projects connected across Catalonia, building relationships for ongoing collaboration:

- Knowledge sharing and mutual support
- Collaboration opportunities
- Collective capacity building
- Preparation for Phase 2 governance

## Key Achievements

### Transparent Impact Documentation

All 11 projects are documenting their regenerative impact on-chain using KarmaGap, creating:

- Verifiable records of regenerative work
- Credibility for future funding applications
- Evidence for policy advocacy
- Learning resources for other projects

### Web3 Capacity Built

Projects have set up wallets and learned tools they'll use for years to come:

- Secure fund management
- Global funding access
- Transparent financial operations
- Integration with impact tools

### Replicable Model Created

The Regenerant Catalunya approach can be adapted by other bioregions globally:

- Open-source knowledge products
- Documented methodologies
- Replicable funding structure
- Transferable capacity-building approach

### Bridge Between Worlds

We've demonstrated that traditional cooperative values can integrate seamlessly with cutting-edge Web3 tools:

- Local knowledge + global infrastructure
- Trusted ecosystems + innovative tools
- Community values + transparent technology
- Bioregional regeneration + global networks

## The Vision: Building Infrastructure, Not Just Providing Funding

This program isn't just about funding projects—it's about building infrastructure for ongoing bioregional regeneration while creating open-source knowledge products that can be adapted globally.

**What This Means:**

- Projects have tools they'll use for years
- Networks have infrastructure for future funding
- Other bioregions can replicate the approach
- Knowledge products enable global adaptation

**The Impact:**

- Sustainable funding infrastructure
- Ongoing regenerative finance capacity
- Replicable model for other regions
- Bridge between local and global

## What's Next: Phase 2 Preview

**Phase 2 (Jan-Feb 2026): Network-Level Collective Governance**

In Phase 2, networks will collectively govern additional funds using Web3 governance tools:

**Miceli Social Network (~€6,000)**

- Rural regenerative projects
- Collective decision-making on fund allocation
- Web3 governance tools (Gardens, Safe multisig)
- Model for ongoing rural regeneration

**La Fundició/Keras Buti Network (~€5,000)**

- Urban regenerative projects
- Collective decision-making on fund allocation
- Web3 governance tools for transparent governance
- Model for ongoing urban regeneration

**What This Creates:**

- Model for ongoing bioregional regeneration
- Infrastructure for future funding rounds
- Experience with Web3 collective governance
- Replicable approach for other bioregions

## Reflection: What We've Learned

### Building Within Trusted Ecosystems Works

Rather than imposing external solutions, building within trusted ecosystems (Miceli Social, La Fundició) enabled:

- Rapid project engagement
- Trust-based relationships
- Respect for existing work
- Sustainable integration

### Capacity Building Takes Time

Projects needed comprehensive support to learn Web3 tools:

- Step-by-step guidance
- Personalized assistance
- Multilingual materials
- Ongoing office hours

### Impact Documentation Is an Investment

Projects that completed comprehensive KarmaGap profiles will have advantages in future funding rounds:

- Verifiable impact records
- Credibility with funders
- Access to new opportunities
- Transparent accountability

### Network Building Is Essential

Connecting projects across Catalonia created:

- Knowledge sharing opportunities
- Collaboration possibilities
- Collective capacity
- Foundation for Phase 2 governance
