### Workshop Planning & Materials Strategy

- **Primary approach decision: Google Docs over direct KarmaGap entry**
    
    - Rationale: Tech accessibility concerns with wallet creation/blockchain interaction
        
    - Alternative considered: Direct KarmaGap project setup rejected due to complexity
        
    - Format: Individual Google Docs per project (not tabs) to avoid confusion for less tech-savvy participants
        
    - Template structure: Based on ReFi Barcelona activities report format
        
        - Activities with start/end dates
            
        - Outputs, deliverables, and metrics for each activity
            
        - Evidence/proof links to compiled materials
            
        - Multiple deliverables per activity capability
            
- **Pre-workshop preparation strategy**

    - Phone usage possible but suboptimal for documentation work
        

### Platform Positioning & Messaging Framework

- **KarmaGap value proposition (refined)**
    
    - Avoid overpromising on current platform capabilities
        
    - Focus areas: Impact tracking, transparency, blockchain permanence
        
    - Future potential: Milestone-based funding allocation programs
        
    - Connection to CIDS (Common Impact Data Standard) for legitimacy
        
    - Real metrics: “€X million disbursed across programs” (specific number to be confirmed)
        
- **Blockchain benefits messaging**
    
    - Transparency and public accountability
        
    - Data resilience (survives platform failures - e.g., if Gitcoin goes down, data remains on-chain)
        
    - Programmable milestone verification for future funding rounds
        
    - **Avoided topics**: Hypercerts integration (no longer viable path)
        
- **Example case studies approach**
    
    - ReFi Foundation as institutional development connection
        
    - Note: ReFi Network not recommended as example (negative reaction observed)
        
    - Goteo integration potential as local relevance angle
        
    - Focus on direct KarmaGap funding round examples vs. broad crypto/Bitcoin analogies
