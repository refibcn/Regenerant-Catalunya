## 2. Google Doc Data Collection System

### Structure: Word Document with Table of Contents

**Master Document:** Single Google Doc with:

- Table of Contents (hyperlinked navigation)
- Master Index section (all projects listed)
- Individual project sections (one per project, clearly separated)

#### Document Structure

**Section 1: Master Index**

- Project names with hyperlinks to their sections
- Contact information
- Network affiliation (Miceli Social / La Fundició)
- Status tracking (wallet opened, Karma account created, activities submitted)
- Quick reference table

**Section 2-12: Individual Project Sections** (one per project, clearly labeled)

Each project section contains:

**A. Project Information**

- Project name, description
- Contact person(s)
- Network affiliation
- Website/social media links

**B. Wallet Setup**

- Wallet address (once created)
- Wallet type (Valora, Minipay, etc.)
- Date wallet opened
- Recovery method (social recovery guardians, etc.)
- Issues encountered / resolved

**C. Past Activities (Minimum 3)**

For each past activity:

- Activity name/description
- Date(s) of activity
- Location
- Participants/beneficiaries
- Impact metrics (quantitative where possible)
- Supporting documents (links to reports, photos, etc.)
- Alignment with evaluation criteria (which criteria does this demonstrate?)
- Status: Draft / Ready for Karma / Submitted

**D. Future Plans (Minimum 3)**

For each future plan:

- Plan name/description
- Timeline
- Expected outcomes
- Resources needed
- How funding will be used
- Alignment with evaluation criteria
- Status: Draft / Ready for Karma / Submitted

**E. Supporting Documents**

- Links to existing reports
- Photos/media
- Other documentation
- Notes on what's available vs. what needs to be created

**F. Evaluation Alignment**

- Self-assessment against 4 criteria
- Strengths identified
- Gaps identified
- Questions for evaluators

**G. Notes & Support**

- Questions from project
- Support provided
- Follow-up needed
- Office hours attendance

### Document Features

- **Hyperlinked Table of Contents** for easy navigation
- **Clear section headers** with consistent formatting
- **Bookmarks** for quick jumping between sections
- **Comment threads** for questions and feedback
- **Version history** enabled for tracking changes

### Access & Permissions

- ReFi Barcelona team: Full edit access
- Project representatives: Edit access to their own section only (using section-level permissions or clear instructions)
- Network coordinators (Oriol, Mariló): View access to their network's projects
- Read-only link for public transparency (optional)

## 3. Workshop 2 Content Development

### Workshop 2: Documenting Impact (December 8-14, 2025)

#### 3.1 Workshop Structure

- **Duration:** 2 hours (with breaks)
- **Format:** Online, interactive
- **Language:** Spanish

#### 3.2 Content Modules

**Module 1: Why Document Impact? (15 min)**

- Importance of impact documentation (beyond crypto)
- Building reputation and discoverability
- Future funding opportunities
- Transparency and accountability

**Module 2: Understanding Evaluation Criteria (20 min)**

- Overview of 4 criteria
- What each criterion means in practice
- Examples from regenerative projects
- How criteria align with project work

**Module 3: Introduction to Karma GAP (20 min)**

- What is Karma GAP
- Why use it
- How it works (on-chain, public, verifiable)
- Common Approach framework alignment

**Module 4: Hands-On Karma Setup (30 min)**

- Creating Karma account
- Connecting wallet
- Navigating the platform
- Setting up project profile

**Module 5: Documenting Activities (30 min)**

- How to log past activities
- How to log future plans
- What information to include
- Examples and templates
- Common mistakes to avoid

**Module 6: Using the Google Doc Template (15 min)**

- How to use the project-specific tab
- Organizing information before Karma submission
- Gathering supporting documents
- Self-assessment against criteria

**Module 7: Q&A and Next Steps (20 min)**

- Office hours schedule
