## Round Logo Creation Workflow

### Overview

The round logo is the primary visual identifier for Regenerant Catalunya event materials. This workflow guides the creation process from design to delivery.

### Design Phase

**Owner:** Andrea (brand lead)

**Step 1: Concept Development**

- Review brand strategy and visual identity guidelines
- Consider visual relationship with future long-term brand
- Explore halftone pattern integration possibilities
- Create initial concept sketches/mockups

**Step 2: Design Specifications**

- Format: Round (circular or square with rounded elements)
- Must work across digital and print applications
- Scalable for various sizes (from favicon to large banners)
- Must maintain elegance and sophistication
- Avoid visual complexity/chaos

**Step 3: Design Iteration**

- Create multiple concept variations
- Test across different applications (web, print, social media)
- Ensure readability at various sizes
- Consider multi-language text integration (if applicable)

**Step 4: Color Application**

- Apply Regenerant Catalunya distinct highlight color
- Test with halftone pattern overlays
- Ensure contrast and readability
- Create variations: full color, single color, reversed

### Review Phase

**Step 5: Team Feedback**

- Present concepts to team
- Gather feedback on visual direction
- Consider usage scenarios
- Refine based on feedback

**Step 6: Multi-Language Considerations**

- Test logo with EN/ES/CAT text (if applicable)
- Ensure cultural appropriateness
- Verify readability across languages

**Step 7: Final Approval**

- Andrea final approval
- Team sign-off on selected design
- Document design decisions

### Delivery Phase

**Step 8: Export Preparation**

**Required Formats:**

- **SVG** (vector, scalable)
  - Use: Web, scalable applications
  - Export: Clean vector paths, optimized file size
- **PNG** (raster, various sizes)
  - 32x32px (favicon)
  - 64x64px (small icons)
  - 128x128px (medium icons)
  - 256x256px (large icons)
  - 512x512px (high-res icons)
  - 1024x1024px (print quality)
  - Export: Transparent background, high resolution

- **PDF** (print)
  - Use: Print materials
  - Export: CMYK color mode, high resolution

**Step 9: Create Usage Guidelines**

- Clear space requirements (minimum distance from other elements)
- Minimum size specifications
- Color variations documentation
- Do's and don'ts
- Integration examples

**Step 10: Template File Creation**

- Create Canva template with logo
- Create Figma file with logo components
- Document export specifications
- Share with team

### Template Files

**Canva Template:**

- Logo placed in template
- Usage guidelines included
- Color palette loaded
- Ready for team self-service

**Figma File:**

- Logo as component
- Variations as instances
- Export settings configured
- For advanced editing

**Access:**

- Canva: Shared brand folder
- Figma: ReFi DAO pro account
- Documentation: Brand guidelines folder

## Halftone Pattern Application Process

### Overview

Halftone patterns (AM screen with green duotone color map) are the core visual treatment for Regenerant Catalunya imagery. This process enables consistent brand application across diverse content.

### Pattern Type Selection Guide

**When to Use Each Pattern Type:**

1. **Dots (Newsprint/AM Screen)**
   - **Best for:** General purpose, editorial aesthetic, classic look
   - **Use cases:** Event photos, general imagery, web banners
   - **Aesthetic:** Classic, timeless, professional

2. **Lines (Line Screen)**
   - **Best for:** Directional emphasis, movement, flow
   - **Use cases:** Action imagery, dynamic content, flow diagrams
   - **Aesthetic:** Dynamic, directional, energetic

3. **Squares/Diamonds (Ordered-Dither/Bayer Matrix)**
   - **Best for:** Tech-forward content, digital aesthetic
   - **Use cases:** Technology imagery, innovation content, digital tools
   - **Aesthetic:** Modern, tech-forward, digital

4. **Crosses/Cross-Hatch**
   - **Best for:** Detailed imagery, complex textures
   - **Use cases:** Complex photos, detailed illustrations, rich imagery
   - **Aesthetic:** Sophisticated, detailed, textured

5. **Custom Glyphs (ASCII/Glyph Halftone)**
   - **Best for:** Unique brand moments, special campaigns
   - **Use cases:** Special events, campaign launches, unique content
   - **Aesthetic:** Unique, branded, memorable
   - **Note:** Requires more design expertise

### Canva Workflow (Primary Tool)

#### Step 1: Prepare Base Image

1. **Upload Image to Canva**
   - Open Canva project
   - Upload your base image
   - Position image as desired

2. **Image Quality Check**
   - Ensure image resolution is appropriate (minimum 1200px width for web)
   - Check image contrast (halftone works best with good contrast)
   - Verify image composition is suitable for pattern overlay

3. **Image Preparation**
   - Adjust brightness/contrast if needed
   - Crop to desired composition
   - Ensure image is properly positioned

#### Step 2: Apply Halftone Pattern

**For Dots Pattern (Newsprint):**

1. **Access Effects Menu**
   - Select image
   - Click "Effects" in toolbar
   - Look for "Halftone" or "Dots" effect

2. **Apply Pattern**
   - Select halftone/dots effect
   - Adjust pattern size (dot size)
   - Adjust pattern density/intensity
   - Preview result

3. **Fine-Tune Settings**
   - Pattern size: Medium (adjust based on image size)
   - Intensity: 50-70% (adjust for desired effect)
   - Angle: 0° (standard) or 45° (diagonal)
   - Preview and adjust until satisfied

**For Lines Pattern:**

1. **Access Effects Menu**
   - Select image
   - Click "Effects"
   - Look for "Lines" or "Line Screen" effect

2. **Apply Pattern**
   - Select lines effect
   - Adjust line spacing
   - Adjust line thickness
   - Set line angle (0°, 45°, 90°, etc.)

3. **Fine-Tune Settings**
   - Line spacing: Medium (adjust based on image)
   - Line thickness: Thin to medium
   - Angle: Choose based on image composition
   - Preview and adjust

**For Squares/Diamonds Pattern:**

1. **Access Effects Menu**
   - Select image
   - Click "Effects"
   - Look for "Pixelate" or "Grid" effect

2. **Apply Pattern**
   - Select pixelate/grid effect
   - Adjust square size
   - Adjust pattern intensity

3. **Fine-Tune Settings**
   - Square size: Small to medium
   - Intensity: 50-70%
   - Preview and adjust

**For Crosses/Cross-Hatch Pattern:**

1. **Apply First Line Screen**
   - Follow "Lines Pattern" steps above
   - Set angle to 45°

2. **Apply Second Line Screen**
   - Duplicate image layer
   - Apply lines effect with different angle (135° or -45°)
   - Adjust opacity to blend layers
   - Combine layers

**For Custom Glyphs Pattern:**

1. **Create Glyph Overlay**
   - Create text or icon elements
   - Convert to pattern overlay
   - Apply as halftone element

2. **Advanced Technique**
   - This requires more advanced Canva features
   - May need to use Figma for custom glyph creation
   - Consult Andrea for custom glyph patterns

#### Step 3: Apply Green Duotone Color Map

**Status:** Specific color mapping values to be defined by Andrea

**General Process:**

1. **Access Color Effects**
   - Select image with halftone pattern applied
   - Access color adjustment tools
   - Look for "Duotone" or "Color Overlay" options

2. **Apply Green Color Map**
   - Select duotone effect
   - Map dark tones to Forest Green (#214033) or darker green
   - Map light tones to lighter green or Warm Sand (#E6DFD7)
   - Adjust color balance

3. **Fine-Tune Color Mapping**
   - Adjust dark/light balance
   - Ensure contrast and readability
   - Test on different backgrounds
   - Preview final result

- Light tones → [Green/Warm Sand TBD]

#### Step 4: Quality Control

**Checklist:**

- [ ] Pattern is clearly visible and consistent
- [ ] Color mapping is accurate and on-brand
- [ ] Image maintains readability

### Figma Workflow (Advanced)

**Use Cases:**

- Advanced pattern combinations
- Custom glyph halftone creation
- Complex design work requiring precision
- Template creation for team use

**Process:**

1. **Set Up Figma File**
   - Open ReFi DAO pro Figma account
   - Create new design file or use brand template
   - Import base image

2. **Apply Pattern Overlay**
   - Create pattern overlay layer
   - Use Figma plugins for halftone effects (if available)
   - Or create pattern manually using shapes/text

3. **Apply Color Mapping**
   - Use Figma color styles
   - Apply green duotone color mapping
   - Adjust opacity and blending modes
   - Fine-tune color balance

4. **Create Template**
   - Save as reusable component
   - Document settings and process
   - Export for team use

**Advanced Techniques:**

- Custom pattern creation
- Multiple pattern layers
- Precise color mapping
- Export optimization

## Troubleshooting Guide

### Common Issues and Solutions

#### Issue: Pattern Not Applying Correctly in Canva

**Symptoms:**

- Pattern effect not available
- Pattern looks incorrect
- Pattern too intense or too subtle

**Solutions:**

1. Check Canva version (ensure latest version)
2. Try different effect options
3. Adjust pattern settings (size, intensity)
4. Consult Canva help documentation
5. Contact Andrea for pattern preset values

#### Issue: Color Mapping Not Accurate

**Symptoms:**

- Colors don't match brand palette
- Duotone effect not working
- Colors look off-brand

**Solutions:**

1. Verify brand color codes are correct
2. Check color mode (RGB for web, CMYK for print)
3. Adjust color balance settings
4. Test on different displays
5. Consult Andrea for color mapping values

#### Issue: Logo Not Displaying Correctly

**Symptoms:**

- Logo appears pixelated
- Logo colors are incorrect
- Logo size is wrong

**Solutions:**

1. Use SVG format for scalable applications
2. Use appropriate PNG size for raster applications
3. Verify logo file is not corrupted
4. Check logo placement guidelines
5. Ensure logo colors match brand palette

#### Issue: Template Not Accessible

**Symptoms:**

- Can't find template in Canva/Figma
- Template appears corrupted
- Template missing elements

**Solutions:**

1. Verify access to shared brand folder
2. Check Canva/Figma account permissions
3. Request access from Andrea
4. Try refreshing/relogging
5. Contact Andrea for template access

#### Issue: Multi-Language Text Issues

**Symptoms:**

- Text doesn't fit in template
- Text appears incorrect
- Character limits exceeded

**Solutions:**

1. Check character limits for platform
2. Adjust text length or font size
3. Verify translations are accurate
4. Test text in all languages
5. Consult brand guidelines for text specifications

## Best Practices

### Pattern Application Best Practices

1. **Choose Appropriate Pattern Type**
   - Match pattern to content type
   - Consider aesthetic goals
   - Test pattern on image before finalizing

2. **Maintain Consistency**
   - Use same pattern type for related materials
   - Keep pattern settings consistent
   - Follow brand guidelines strictly

3. **Ensure Readability**
   - Don't let pattern overwhelm content
   - Maintain contrast and clarity
   - Test at various sizes

4. **Quality Over Speed**
   - Take time to fine-tune settings
   - Test before finalizing
   - Review quality control checklist

### Template Usage Best Practices

1. **Always Start from Template**
   - Don't create from scratch
   - Use approved templates only
   - Follow template structure

2. **Maintain Brand Consistency**
   - Don't modify core brand elements
   - Follow brand guidelines
   - Use approved assets only

3. **Test Before Finalizing**
   - Preview at various sizes
   - Test on different platforms
   - Verify all elements are correct

4. **Document Your Work**
   - Note any customizations
   - Document settings used
   - Keep track of versions

### Collaboration Best Practices

1. **Communicate Early**
   - Share work-in-progress for feedback
   - Ask questions before problems arise
   - Consult Andrea for brand-critical decisions

2. **Follow Review Process**
   - Complete quality control checklist
   - Get appropriate approvals
   - Document feedback and changes

3. **Share Learnings**
   - Document new techniques discovered
   - Share template improvements
   - Contribute to process refinement
