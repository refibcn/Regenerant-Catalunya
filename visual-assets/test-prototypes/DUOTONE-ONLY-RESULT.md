## Color Mapping

The duotone process:

1. Analyzes luminance of each pixel
2. Maps dark tones → Forest Green (#214033)
3. Maps light tones → Warm Sand (#E6DFD7)
4. Creates smooth gradient transitions
5. Preserves all image detail and structure
